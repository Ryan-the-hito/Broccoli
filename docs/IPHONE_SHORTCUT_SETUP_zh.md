# 从 iPhone 向 Broccoli 提问

<p><b>简体中文</b> · <a href="IPHONE_SHORTCUT_SETUP.md">English</a> · <a href="IPHONE_SHORTCUT_SETUP_ja.md">日本語</a></p>

这份说明教你在 iPhone 上做一个叫 **Broccoli** 的快捷指令。每次运行，它会做三件事：

1. 问你让哪台 Mac 来回答。
2. 问你是开一个新对话，还是接着那台 Mac 最近 30 个对话中的某一个。
3. 问你要问什么。

Mac 回答后，答案出现在「**备忘录**」App 里一个叫 **Broccoli** 的文件夹中；答好时，iPhone 上还会有一条提醒。

这个快捷指令只读写「快捷指令」App 自己的 iCloud 文件夹，里面没有任何名字或设备编号，所以可以直接用链接分享给任何人。

> 下面的 iOS 动作名都用英文写，括号里是中文系统里常见的叫法。不同 iOS 版本的中文名可能略有不同，搜不到时可以换个近似的词搜。

## 需要准备

- 至少一台运行 Broccoli（这一版或更新）的 Mac。
- iPhone 和 Mac 登录**同一个 Apple 账户**，两边都打开 **iCloud 云盘**。
- iPhone 是 iOS 18 或更新（第 0 步要用到）。
- Broccoli 的「设置 › 通用 › 历史与 iCloud」里，「**iCloud 远程任务**」下的开关「**Apple 备忘录镜像 + iPhone 快捷指令**」是打开的。默认就是开的。

## 开始之前：每台 Mac 上做一次

1. 退出 Broccoli，再重新打开。
2. 等大约 15 秒。Broccoli 会在「快捷指令」App 的 iCloud 文件夹里建一个叫 **Broccoli** 的文件夹。

想在 iPhone 上选到的每一台 Mac 都要做一次。运行旧版 Broccoli 的 Mac 不会出现在列表里。

## 第 0 步：让 iPhone 一直保留 Broccoli 文件夹

iCloud 有时只在 iPhone 上显示文件，却不真正下载。这时快捷指令读不到文件，会报错停下。这个设置打开一次，iCloud 就会把这个文件夹里的文件一直留在 iPhone 上，包括 Mac 以后更新的文件。

1. 打开「**文件**」App，点「**浏览**」。
2. 点「**iCloud 云盘**」，再点「**快捷指令**」。
3. 确认里面有一个 **Broccoli** 文件夹。没有的话等一分钟让 iCloud 同步；还是没有，就回到"开始之前"。
4. **按住** **Broccoli** 文件夹，不要点开它。
5. 点「**保持下载**」（Keep Downloaded）。下次再按住这个文件夹，这一项前面会有一个勾。

这个文件夹里只有几个很小的文本文件，几乎不占空间。

## 做这个快捷指令

每个动作都从编辑器底部的搜索框（「**搜索操作**」）里添加。下面说的"框"，是动作里蓝色的那一格，点一下就能改。

> **注意自动填好的框。** 添加一个动作时，快捷指令常常会把上一个动作的结果自动填进它的第一个框。如果某个框里写的和步骤里说的不一样，点它，选「**清除变量**」，再按步骤设好。

1. 打开「**快捷指令**」，点「**快捷指令**」标签，再点右上角的 **+**。
2. 点最上面的名字，点「**重新命名**」，输入 `Broccoli`。

**选 Mac**

3. 添加 **Get File from Folder**（从文件夹获取文件）。它显示为"从 [快捷指令] 的 [路径] 获取文件"。
   - 第一个框应该是「**快捷指令**」。如果是空的，点它，选「**iCloud 云盘 › 快捷指令**」，点「**打开**」。
   - 点"路径"那个框，输入 `Broccoli/Macs.txt`。
4. 添加 **Split Text**（拆分文本）。它应该显示为"按 [新行] 拆分 [文件]"。
5. 添加 **Choose from List**（从列表中选取）。点小箭头展开，在"提示"里输入 `Which Mac?`。
6. 添加 **Set Variable**（设定变量）。变量名输入 `Mac`。它的值应该是"所选项目"。

**选对话**

7. 再添加一个 **Get File from Folder**（从文件夹获取文件）。
   - 第一个框多半被自动填成了 **Mac**。点它，选「**清除变量**」，确认它是「**快捷指令**」，和第 3 步一样。
   - 点"路径"框。先输入 `Broccoli/Lists/`（包括最后的斜杠），再点键盘上方变量栏里的 **Mac**；变量栏里没有的话，点「**选择变量**」选 **Mac**。然后输入 `.txt`。
   - 这个框现在是：`Broccoli/Lists/` **Mac** `.txt`
8. 添加 **Split Text**（拆分文本）。它的第一个框必须是第 7 步的"文件"，按"新行"拆分。
9. 添加 **Choose from List**（从列表中选取），"提示"输入 `Which conversation?`。
10. 添加 **Set Variable**（设定变量）。变量名输入 `Chat`。它的值应该是第 9 步的"所选项目"。

**输入问题**

11. 添加 **Ask for Input**（要求输入）。类型保持"文本"，"提示"输入 `What do you want to ask?`。
12. 添加 **Text**（文本）。里面正好放三行，不要多余的空格或空行：
    - **Mac** 变量
    - **Chat** 变量
    - "提供的输入"

**存到 Mac 会去看的地方**

13. 添加 **Format Date**（格式化日期）。
    - 日期设为"当前日期"。
    - "日期格式"选"自定义"。
    - "格式字符串"输入 `yyyyMMdd-HHmmss`。
14. 添加 **Set Name**（设定名称）。
    - 点第一个框，点「**选择变量**」，选第 12 步的"文本"。
    - 点"名称"框，插入"格式化的日期"，再输入 `.txt`。
15. 添加 **Save File**（存储文件）并展开。
    - 输入应该是"重新命名的项目"。
    - 关掉「**询问存储位置**」。
    - 文件夹保持「**快捷指令**」。
    - "子路径"输入 `Broccoli/Inbox/`。这里不用写文件名，"设定名称"已经给好了。
    - 「**如果文件存在则覆盖**」保持关闭。
16. 可选：添加 **Show Notification**（显示通知），文字写成 `Sent to` 加上 **Mac** 变量之类。
17. 点「**完成**」。

## 试一下

1. 运行这个快捷指令。选一台 Mac，选新对话，输入一个简短的问题。
2. 如果 iPhone 问这个快捷指令能否访问文件，选「**始终允许**」。
3. 马上打开「**文件 › iCloud 云盘 › 快捷指令 › Broccoli › Inbox**」。
   - 你应该能看到一个以日期时间命名的文件，比如 `20261031-153000.txt`，说明存好了。
   - 如果那台 Mac 开着，这个文件几秒内就会消失，说明 Mac 已经接走了。

## Mac 第一次回答时

- Mac 会问 Broccoli 能不能控制「**备忘录**」，之后还会问「**提醒事项**」。两次都点「**好**」。如果拒绝了，Broccoli 会提示一次去哪里改。
- 在 iPhone 上允许「提醒事项」发通知（「**设置 › 通知 › 提醒事项**」），否则提醒不会响。

## 日常使用

**Mac 列表**

- 列出所有运行这一版 Broccoli、最近 30 天内出现过的 Mac。
- 关机、睡眠或没开 Broccoli 的 Mac 会显示成比如 **MacBook Pro 💤（离线）**，用的是那台 Mac 自己的语言。
- 离线的 Mac 也可以选。问题会在 iCloud 里等着，那台 Mac 回来后就会回答。

**对话列表**

- 第一行是新建对话，用那台 Mac 的语言显示。
- 下面是那台 Mac 最近的最多 30 个对话，新的在前，每个显示为 `标题 · 编号`。编号用来区分同名的对话。
- 选一个对话，就会在那台 Mac 上接着它问，带着之前的上下文。

**回答**

- 每个回答是「**备忘录 › Broccoli**」里的一条备忘录，标题是问题的开头加一个短编号。
- 标题以 ⚠️ 开头，表示这个问题没有回答，备忘录里写了原因，你的问题也保留在里面。
- 标题以 ⏳ 开头，表示 Mac 在等你批准某个操作。回答会另写一条备忘录。
- 备忘录写好大约一分钟后，「**提醒事项**」里 **Broccoli** 列表中的一条提醒会响。提醒一天后会自己勾掉。
- 不想要提醒，可以关掉 Broccoli 设置里「**iCloud 远程任务**」下的「**回答好了在 iPhone 上提醒我**」。
- 删掉备忘录或提醒不会影响任何东西，对话都存在 Mac 上。

## 分享给别人

1. 按住 **Broccoli** 快捷指令，点「**共享 › 拷贝 iCloud 链接**」。
2. 把链接发给对方。对方点「**添加快捷指令**」就行，什么都不用改。
3. 对方需要和你一样的准备：自己的 Mac 上有 Broccoli，并打开 iCloud 云盘；在自己的 iPhone 上做一次第 0 步。他的问题会进他自己的 iCloud，由他自己的 Mac 回答。

## 看起来不一样或出错时

- **快捷指令在第 3 步或第 7 步停下，报"找不到文件"或"不存在"。**
  - 如果跳过了第 0 步，先做第 0 步。
  - 如果你的 iPhone 没有「保持下载」，打开「**文件 › iCloud 云盘 › 快捷指令 › Broccoli**」，点一下 `Macs.txt` 和 **Lists** 里的文件让它们下载，再运行一次。
  - 如果只有第 7 步出错，你选的那台 Mac 可能在运行旧版 Broccoli。
- **列表只显示一长条，而不是一行一项。** 两处都在 **Get File from Folder**（从文件夹获取文件）和 **Split Text**（拆分文本）之间加一个 **Get Text from Input**（从输入中获取文本）。
- **Save File（存储文件）没有"子路径"。** 改为点文件夹，选「**快捷指令 › Broccoli › Inbox**」。这样你自己用没问题，但分享给别人后，对方可能要重新选一次文件夹。
- **Inbox 里的文件叫 `Text.txt`。** 第 15 步的输入必须是"重新命名的项目"，不是"文本"。
- **文件一直留在 Inbox 里。** 你选的那台 Mac 关机或睡眠了。它回来后就会回答。

## 还没在真 iPhone 上测过的地方

- 动作和选项的名字来自目前的社区资料和早期反馈，在你的 iOS 版本上可能略有不同；括号里的中文名也是常见叫法，没有逐个核对。
- 苹果的说明里，「保持下载」适用于 iCloud 云盘的文件夹。有两点还没确认：
  - Mac 后来改动的文件，是否也会自动下载；
  - 它对「快捷指令」App 自己的文件夹是否也有效。

  检查方法：在一台 Mac 上开一个新对话，让它的列表变一下。过一两分钟，打开「**文件 › … › Broccoli › Lists**」。如果文件旁边没有云朵图标，说明它们在自动下载。
